Tráiler en YouTube

Se quitó el width y height del código de «Compartir → Incorporar» y se colocó el iframe dentro de un contenedor que mantiene la proporción 16:9.

¿Ves «Error 153»? Abriste el HTML con doble clic (file://): no hay un sitio web que YouTube pueda identificar, así que bloquea el video. Ábrelo con Live Server (http://) y funcionará.

.video-responsive { position: relative; padding-bottom: 56.25%; height: 0; } .video-responsive iframe { position: absolute; top: 0; left: 0; width: 100%; height: 100%; }

Alternativa moderna (Sesión 6): iframe { width: 100%; aspect-ratio: 16 / 9; }. Para Vimeo el procedimiento es el mismo: «Compartir → Insertar» y pegar el iframe.

El Halcón cruza el espacio

Video propio con controls, loop y poster. El navegador intenta primero el MP4; si no puede, prueba el WebM; si tampoco, muestra el texto alternativo.

Reproducir desde un momento concreto

Con #t=3,6 al final del src, el video se reproduce solo del segundo 3 al 6.

MP4 vs. WebM

MP4 (códec H.264) es el estándar más compatible. WebM (códecs VP8/VP9) es la alternativa libre creada por Google para HTML5. Ofrecer ambos con <source> garantiza que el video se vea en cualquier navegador.
